# HR Analytics & Employee Attrition Analysis

## Project Overview

An end-to-end HR Analytics project focused on understanding employee attrition, workforce trends, employee experience, compensation, and career growth.

The project uses Python for data analysis, MySQL for data validation and business queries, and Power BI for interactive dashboard reporting.

## Business Objectives

- Analyze overall employee attrition and retention.
- Identify attrition patterns across departments and job roles.
- Explore overtime, job satisfaction, and work-life balance.
- Examine monthly income, job levels, and career progression.
- Present workforce insights through an interactive dashboard.

## Tools & Technologies

- Python — Pandas, Matplotlib, Seaborn
- MySQL — Data validation and business analysis
- Power BI — Interactive dashboard
- Jupyter Notebook — Python analysis

## Dashboard Pages

1. HR Overview
2. Attrition Analysis
3. Employee Experience
4. Compensation & Career Growth

## Key Metrics

- Total Employees: 1,500
- Employees Who Left: 209
- Attrition Rate: 13.93%
- Employees Retained: 1,291
